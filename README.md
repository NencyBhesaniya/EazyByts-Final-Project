# 📰 News Aggregator

A simple, responsive news aggregator web application. This app displays news cards with a clean layout, reusable components, and modular styling.

## 🚀 Features

- 📄 Modular components: `Header`, `Footer`, and `NewsCard`
- 🎨 Styled using Tailwind CSS
- ⚡ Fast performance with Next.js
- 📱 Mobile-responsive design
- 🧩 Organized project structure

## 📁 Project Structure

```
├── components
│   ├── Footer.jsx
│   ├── Header.jsx
│   └── NewsCard.jsx
├── pages
│   ├── _app.js
│   └── index.js
├── public
│   ├── favicon.ico
│   └── vercel.svg
├── styles
│   ├── globals.css
│   └── Home.module.css
```

## 🛠️ Getting Started

### 1. Clone the repository

```bash
git clone https://github.com/yourusername/news-aggregator.git
cd news-aggregator
```

### 2. Install dependencies

```bash
npm install
# or
yarn install
```

### 3. Run the development server

```bash
npm run dev
# or
yarn dev
```

Visit `http://localhost:3000` to see the app in action.
